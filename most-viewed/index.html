AUDIENCE DATA

Popularity should be based on real viewing information

A documentary should appear as most viewed only when relevant audience data supports that description. Viewing activity can differ between platforms, reporting periods and language editions.

For that reason, this global gateway does not assign documentary positions or publish numerical view counts unless those details are supported by the relevant publishing or audience data.

DISCOVERY CONTEXT

What “Most Viewed” means here

Popularity can help visitors discover documentary content, but it is separate from editorial assessment.

01

Data before ranking

Popularity labels should be supported by available audience information rather than assumptions or manually invented positions.

02

Edition-specific context

Bengali, English and Hindi editions can have different audiences, publishing histories and viewing patterns, so their popularity signals should not be treated as interchangeable.

03

Popularity is not endorsement

Higher viewing activity does not by itself indicate that a documentary is more authoritative, important or editorially selected.

GLOBAL DIRECTORY

One gateway, multiple audience contexts

SalimGPT Global connects visitors to the official language editions rather than duplicating documentary pages or manufacturing a single cross-language ranking. Documentary availability and audience activity can differ between editions.
